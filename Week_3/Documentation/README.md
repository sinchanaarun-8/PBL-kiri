# Week 3 Documentation

This folder contains the design, testing, and performance analysis documentation for the Process Scheduling Simulator.

## Documents
- `architecture.md` — Project structure and integration design.
- `algorithm_explanation.md` — Explanation of the scheduling algorithms.
- `test_cases.md` — Test scenarios and expected results.
- `performance_comparison.md` — Comparison of scheduling algorithms using their performance metrics.

## Required Performance Metrics
- Completion Time (CT)
- Turnaround Time (TAT) = CT - Arrival Time
- Waiting Time (WT) = TAT - Burst Time
- Response Time (RT) = First CPU Start Time - Arrival Time
- CPU Utilization = (CPU Busy Time / Total Elapsed Time) × 100

Actual results will be documented after the algorithms are integrated and tested.
